# 🎵 Interactive Web Music Player

> 🔗 **Live Web Player Demo**: [https://javascript-music-player-eight.vercel.app](https://javascript-music-player-eight.vercel.app)  
> 🛠️ **Tech Stack**: HTML5 Audio API, CSS3 Glassmorphism, Vanilla ES6+ JavaScript

---

## 🌟 Overview
A sleek, responsive browser-based music player built with Vanilla JavaScript and the HTML5 Audio API. It features real-time audio playback controls, dynamic seek bar tracking, volume adjustment, and a synchronized playlist queue.

---

## 🚀 Key Features

- ⏯️ **Playback Controls**: Play, Pause, Next Track, Previous Track, and Auto-Advance on song completion.
- ⏱️ **Interactive Seek Bar**: Real-time elapsed / total time tracking with a draggable scrubber for instant seeking.
- 🔊 **Volume Controls**: Smooth slider control for sound output with mute toggle capability.
- 💿 **Dynamic Track Artwork**: Synchronized album art, song title, and artist metadata transitions.
- 🎨 **Glassmorphic Modern Design**: Modern blur effects and responsive layout designed for both desktop and mobile.
